## Checking for updates

**Check for Updates…** in the menu bar menu, or the **Updates** card in <Path to="Settings → About" />, asks GitHub for the newest release and says whether you have it.

With **Check automatically** on, which it is unless you turn it off, Dynotch asks once a day, a little after launch, and announces a new version in the notch. The check is one request to `api.github.com` that carries nothing but the app's version.

## Installing an update

**Install and Relaunch** in <Path to="Settings → About" /> does the rest:

1. It downloads the release's zip.
2. It checks that the app inside is Dynotch, that it's the version announced and newer, and that it's signed with the same certificate as the copy you have.
3. It puts the new version in place and reopens Dynotch, which says so in the notch.

Only the key that signs Dynotch's releases can make an app that passes, so a tampered download is refused. Settings, notes, Tray files and the permissions you gave it all stay, because macOS sees the same app.

<Note>
  A copy that can't replace itself, like one run straight from the disk image, offers **Download** instead. It opens the new disk image in your browser. Quit Dynotch from its menu bar icon, then replace the app in Applications.
</Note>

**Install and Relaunch** arrived in 1.3.0. Coming from 1.2.1 or earlier, replace the app by hand once.

## Uninstalling

1. If **Launch at login** is on, turn it off in <Path to="Settings → General" /> first.
2. Quit Dynotch and move it from Applications to the Trash.
3. To remove what it saved as well:

   ```bash
   rm -rf ~/Library/Application\ Support/Dynotch
   defaults delete app.dynotch.Dynotch
   ```

   <Note warn>This deletes the notes and Tray files kept there. Notes you moved to iCloud Drive stay in its **Dynotch Notes** folder.</Note>

4. The permissions you gave it stay listed in <Path to="System Settings → Privacy & Security" /> until you remove them there.
