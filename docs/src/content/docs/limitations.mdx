---
title: Limitations
description: What Dynotch can't do, and why.
---

## Now Playing covers Apple Music and Spotify

Since macOS 15.4, other players (browsers, Podcasts and so on) only report to the private MediaRemote framework, which macOS reserves for Apple-signed processes. Apps that show every player work around this by loading code into an Apple-signed binary. Dynotch doesn't do that.

## The volume HUD shows alongside the system's

The volume and brightness HUD appears alongside the system one unless **Replace system HUD** is on, which needs Accessibility. See [Audio and keys](/audio-keys/#replace-system-hud).

## The equalizer is decorative by default

The bars are decorative unless **Live equalizer** is on. That needs macOS 14.2 or later and the System Audio Recording permission, and follows Music and Spotify only. macOS has no public API to check that permission, so Dynotch asks the private TCC framework, as other audio tools do.

## Brightness relies on a private framework

The brightness HUD and the Control tab's brightness slider reach the built-in display through the private DisplayServices framework. If that's unavailable, the HUD stays quiet and the slider isn't shown.

## Which Focus is on is read from undocumented files

Which Focus is on comes from Focus settings files that Apple doesn't document. A scheduled Focus switched off by hand is recognized by the record macOS keeps of what was switched off, using the key names in macOS's own Focus code, but that hasn't been checked against a real switch-off yet. See [The notch shows the wrong Focus](/troubleshooting/#the-notch-shows-the-wrong-focus).

## Notification peeks read an undocumented database

Its location and layout have changed between macOS versions before. If they change again, Settings says notifications can't be read on that Mac. They were last checked on macOS 27.0.1.

## The usage ring only hears from terminal sessions

Claude Code runs its status line in the terminal, not in sessions started in the desktop app. While you work there, the [ring](/claude-usage/) stays at whatever a terminal session last reported, and says how old that is.

## Glass needs macOS 26

Liquid Glass is on macOS 26 and later. On earlier versions, the open notch is black.

## The first Copy Text can take a while

The first time Dynotch reads text, macOS prepares its models for it, which took up to half a minute on a busy Mac. The capture closes at once, and the notch says it's reading until that's done. After that, a read takes a fraction of a second.

## Copy Text can miss small text

In testing on a very busy Mac, about one first read in twelve went wrong: macOS's text reader came back with only the biggest text on the page, and kept doing that. It looks like it's in how macOS stores the models it prepared, not in Dynotch, and what sets it off isn't known. If Copy Text only finds a page's title, quit Dynotch, delete its `com.apple.e5rt.e5bundlecache` folder from `~/Library/Caches`, and open Dynotch again.

## A cut-out is in sRGB

Vision hands back a cut-out's subject in sRGB, whatever the photo was in. Colors that sRGB can't hold, which a phone's photos can have, come out a little less vivid.

## Recordings have no sound

A [recording](/capture/#recording) has no sound of any kind, neither the Mac's nor the microphone's. Recording the microphone would need its entitlement, which Dynotch doesn't have, and that's a separate choice.

## Translate and Summarize need macOS 26

Both come from macOS, and neither sends anything off your Mac. On earlier versions they aren't offered, and `tr` in the command field says so.

- **Translate** only uses languages already installed. Add them in <Path to="System Settings → General → Language & Region → Translation Languages" />. Asking for a download takes a window Dynotch doesn't have, so the notice has a button to that page instead. macOS can't translate every language: Urdu, for one, isn't among them yet. It takes the first 20,000 characters of a longer text, and the notice says so.
- **Summarize** needs Apple Intelligence turned on, on a Mac that can run it. It can only read about 9,000 characters at a time, so a longer text gets a summary of its start, and the notice says so.

## Not notarized

Dynotch isn't notarized by Apple, so the first launch needs [one extra step](/install/#get-past-the-first-launch).

## Left out on purpose

Not included from MacNotch: Night Shift and True Tone toggles, which have no public API.
