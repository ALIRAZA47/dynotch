## What it can tell

Safari records its progress, so you get a real percentage. Chrome, Firefox and Opera only write a partial file that grows, so you get the size so far.

## Putting them in the Tray

Turn on **Downloads to the Tray** in <Path to="Settings → Live Activities → Options" /> to put each finished download in the [Tray](/tray/).

## Permission

It needs access to the Downloads folder. macOS asks the first time.

To turn it off altogether, switch off both **Downloads** and **Downloads to the Tray** in <Path to="Settings → Live Activities" />. Either one keeps Dynotch watching the folder.
