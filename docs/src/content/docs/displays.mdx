## Choosing displays

<Path to="Settings → General → Show the notch on" /> picks where it appears:

| Choice | Where |
|---|---|
| Built-in display | The screen with a camera notch, or the first display if none has one. This is how it starts |
| Main display | Whichever display is main |
| All displays | Every one of them |

## The virtual notch

Displays without a camera notch get a virtual one that hangs from the top edge. It works the same as the real thing.

## The line

If you'd rather not cover anything, choose **Line** in <Path to="Settings → Appearance → Virtual notch" />. The closed notch rests as a faint line along the top edge, and grows into the full virtual notch while something's showing, when you hover and when it opens.

Activities still expand it, so clamshell and external-display setups keep them. Turning them off in <Path to="Settings → Live Activities" /> keeps it flat most of the time, but a few notices still show: a timer ending, a screenshot landing in the Tray, the mic muting, rain, a new version, and whatever your scripts send.

## Width

**Width** in <Path to="Settings → Appearance → Virtual notch" /> sets how wide the virtual notch is, from 140 to 280 points. It starts at 190.
