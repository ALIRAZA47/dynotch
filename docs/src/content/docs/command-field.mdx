Press <Keys k="⌃⌥K" /> from anywhere, or click **Type a command** in the open notch's header. With nothing typed, it lists what you use most, then one of each thing it can do.

<Shot name="command-1-empty" eager alt="The command field open and empty, suggesting a timer, a note, a reminder, Dark Mode, a profile and a sum." />

## What you can type

| Type | And Dynotch |
|---|---|
| `tea 4m` | Starts a timer called Tea |
| `note Buy coffee` | Adds a note |
| `remind Call Sam 5pm` | Adds a reminder |
| `cal dentist fri 3pm` | Adds a calendar event |
| `18% of 240` | Answers, and Return copies it |
| `5 km to mi`, `1.5 gb to mb` | Converts, and Return copies it |
| `5pm pst in lahore`, `time in tokyo` | Says what time that is somewhere else |
| `2026-10-31`, `days until 25 dec` | Says which day that is, or counts the days to it |
| `#a894ff to rgb` | Writes a color another way |
| `tr hola to english` | Translates on your Mac, and copies it |
| `dark` | Flips Dark Mode |
| `awake` | Keeps the Mac awake |
| `awake 2h`, `awake until 5pm`, `awake off` | Keeps it awake for a while, or stops |
| `mute` | Mutes the microphone |
| `pomodoro` | Starts or pauses a focus session |
| `stopwatch` | Starts or pauses the stopwatch |
| `color` | Picks a color from the screen and copies its hex code |
| `screenshot` | Starts a [capture](/capture/) |
| `stop`, `stop recording` | Stops a [recording](/capture/#recording), while one runs |
| `sleep` | Sleeps the display |
| `next`, `previous`, `pause` | Controls the music, while a player is open |
| `vol 30`, `bright 60` | Sets the volume or the built-in display's brightness |
| `output AirPods` | Switches the sound's output. `output` alone lists them |
| `connect keyboard`, `disconnect AirPods` | Connects or disconnects a Bluetooth device |
| `join` | Joins the meeting that's on, or the next one today with a link |
| `clear tray` | Clears the Tray, all but what's pinned |
| `clip`, `clip rebase` | Lists or searches what you've [copied](/tray/#clipboard), pinned first, and Return copies it back. `clips` and `clipboard` work too |
| `run Morning routine` | Runs a Shortcut |
| `Work`, or `profile Work` | Switches to that [profile](/profiles/) |
| `tray`, `focus`, `control` | Opens a tab |
| `settings`, `settings tray` | Opens Settings, or one of its pages |

It also finds notes and Tray files by what's in their names and text, so typing a word from a note brings it up. What you've copied only shows on a line that starts with `clip`.

<Note>`focus` starts with the same word as a focus session, so that row comes first and Return runs it. To open the tab, press <Keys k="↓" /> first.</Note>

## Timers

A name and a time starts a timer. `eggs 90s`, `nap 1h30` and `laundry 45` all work, and a number on its own means minutes. Timers run up to 24 hours. See [Focus](/focus/#named-timers).

<Shot name="command-2-timer" alt="The command field with tea 4m typed in, offering to start Tea for four minutes." />

## Reminders

The time comes out of the title, so `remind Call Sam 5pm` makes a reminder called "Call Sam", due at five. A time that's passed means tomorrow.

<Shot name="command-4-reminder" alt="The command field with remind Call Sam 5pm typed in, offering a reminder called Call Sam for today at 17:00." />

The reminder goes to the Reminders app, so it needs the Reminders permission. The field asks for it the first time.

## Events

`cal` adds an event to your default calendar, for an hour unless you say otherwise. The name goes first, then the day and the time side by side, and the row shows what it read before you press <Keys k="Return" />.

| Type | And Dynotch adds |
|---|---|
| `cal dentist fri 3pm` | Dentist, on Friday from 3 to 4 |
| `cal dentist today 3pm` | Today. A time on its own isn't enough |
| `cal standup mon 9am 30m` | Half an hour |
| `cal review fri 2pm for 45 min` | 45 minutes |
| `cal lunch fri 12-1pm` | From noon to one |
| `cal call fri 3pm est`, `cal call fri 3pm lahore time` | At 3 in that zone, shown in your own time. The zone goes last |

The day can be `today`, `tonight`, `this evening`, `tomorrow`, a weekday, `friday night`, `next fri`, `25 dec`, `dec 25 2027` or `2026-12-25`. Dates with slashes, like `11/13`, aren't read, as they mean different days to different people.

A wrong event is worse than no event, so anything it can't be sure of, the row says, and <Keys k="Return" /> adds nothing:

| The row says | For |
|---|---|
| No time in that yet | A day on its own, like `cal dentist fri`, or `tonight` and `tomorrow morning` with no clock time. A number with a dot, like `15.50`, is taken for an amount |
| No day in that yet | A time with no day it can read, which is where `tomorow`, `next week` or `5th` end up. `today` is enough |
| Add am or pm to the time | `3:30` or `at 5`, which could be either, `9-2am`, which could run past midnight from either end, or `9-12pm`, which could be morning or evening. `09:30`, `15:30`, `noon` and `tonight at 8` are fine |
| Put the day beside the time | `fri dentist 3pm`, or `fri with sam 3pm`. Without this, `SAT prep 3pm` would be on Saturday |
| Put the name first | Words after the time, like `fri 3pm with sam` |
| Can't read the day in that | A day that the words beside it change, like `black friday`, `2nd fri`, `every friday` or `a week on fri`, or a time that doesn't fit it, like `tonight 3pm` |
| That reads as more than one time | Two times or two days in one line, or `3 or 4pm` |
| There's no such date | `nov 31`, a weekday the date doesn't fall on, or a time the clocks skip that night |
| Say when it starts | `until 5pm` on its own |
| Can't read how long that is | A length over a day, like `for 3 days`, a length in words, or one ahead of the day |
| Can't read the time zone in that | A zone ahead of the time, or initials that mean other things, like `pt`, `ct` and `bst`. Use `pst`, `cst`, `london time` or `pacific time` |
| That time has passed | A time that's gone, today or on a day that's over |

`in 2 hours` isn't understood yet. A weekday means today if it's that day, and the coming one if not. `next fri` means the Friday of next week. A date with no year means the coming one, unless it's in the last month.

The event goes to the Calendar app, so it needs the Calendar permission. The field asks for it the first time.

## Sums and conversions

Answers show up as you type, and Return copies them. All of it is worked out on your Mac.

<Shot name="command-3-sum" alt="The command field with 18% of 240 typed in, answering 43.2." />

Conversions cover length, mass, temperature, volume, speed and data sizes. Sizes go in thousands, as macOS counts them, so `1 gb to mb` is 1000. For 1,024s, use `kib`, `mib`, `gib` and `tib`.

## Times, dates and colors

| Type | And Dynotch |
|---|---|
| `5pm pst in lahore` | The same moment in Lahore, with the day if it's a different one |
| `3:30pm london to tokyo` | The same, from one place to another |
| `noon in nyc` | Your noon, there |
| `time in tokyo`, `tokyo time` | The time there now |
| `2026-10-31` | Which day that is, and how far off |
| `days until 25 dec`, `days since 1 jan 2020` | How many days. With no year, it's the coming one, or the last one with `since` |
| `#a894ff to rgb`, `to hsl`, `rgb(168, 148, 255) to hex` | The color written another way |

Any city macOS has a time zone for works, along with a short list of others, like Lahore, San Francisco and Mumbai, and a zone's initials. Initials mean that zone's clock rather than a fixed offset, so in summer `pst` is read as PDT and `cet` as GMT+2, and the answer shows the one it used.

## Translating

`tr hola to english` translates with macOS, on your Mac, and copies the answer. `translate` works too.

| Type | And Dynotch translates |
|---|---|
| `tr hola to english` | To English, working out what it's in |
| `tr chat from french to english` | From French, for a word that could be several languages |
| `tr bonjour` | To your Mac's language |

It needs macOS 26 and languages that are already installed. If they aren't, the notice says which to add and has a button to the right page. See [Limitations](/limitations/#translate-and-summarize-need-macos-26).

## Moving around

| Key | What it does |
|---|---|
| <Keys k="↑ ↓" /> | Picks a row |
| <Keys k="Return" /> | Runs it |
| <Keys k="Esc" /> | Clears what's typed, and then leaves |

## What you use comes first

The commands you've run lately and run often rise to the top of the empty field, so <Keys k="⌃⌥K" /> then <Keys k="Return" /> repeats the one you use most, if it needs nothing more. A timer, a note, a reminder, an event, a sum, a translation or a level fills the field for you to finish. Only the command is counted, like **Keep the Mac awake** or a Shortcut by its name, with how often and when you last ran it. What you type is never kept: `tea 4m` counts as a timer, and a note counts as a note.

A Shortcut, a profile, **Join** and **Sleep** are typed out by the first <Keys k="Return" />, and the second runs them, so a stray one can't. Clearing the Tray and disconnecting a device never show up there at all. Nor do outputs and connecting a device.

## Turning it off

**Open it with <Keys k="⌃⌥K" />** in <Path to="Settings → General → Command field" /> turns off the shortcut. The field is still there in the open notch's header.

**Suggest what you use**, in the same place, goes back to the same six suggestions and forgets what it counted.
