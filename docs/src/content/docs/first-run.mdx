## Permissions

The third step lists the permissions worth allowing, each with its status and an Allow or Open System Settings button. Allow what you'd like now. The rest are asked for when a feature first needs them, so you can skip this and lose nothing.

## Try these first

1. **Rest the pointer on the notch.** It grows into a [glance](/dynotch/glance/) at what's live. Move away and it closes.
2. **Click it.** The whole notch opens on the [Nook](/dynotch/nook/), with your music and calendar.
3. **Swipe sideways** over the open notch to move between its tabs.
4. **Press <Keys k="⌃⌥K" /> and type `tea 4m`,** then Return. A four minute timer starts, and the closed notch counts it down.
5. **Drag a file toward the notch.** It opens with [drop zones](/dynotch/tray/), so you can keep the file close, send it or compress it.
