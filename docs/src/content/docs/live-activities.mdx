With the notch closed, what's going on shows up beside the camera, without opening anything. The closed notch stays black, so it blends with the camera housing, and grows only as far as it has to.

<Shot name="03-closed-music" eager alt="A MacBook menu bar with the closed notch showing album art on its left and an equalizer on its right." />

## What it can show

Each one has a switch in <Path to="Settings → Live Activities" />. All of them start on.

| Activity | What it shows |
|---|---|
| Now playing | Artwork and an equalizer while music plays |
| Track changes | The song's name when the track changes |
| Focus timer | A countdown while the timer runs |
| Volume & brightness | A meter as you change them |
| Charging | The battery level when you plug in |
| Low battery | For the Mac and Bluetooth devices |
| Upcoming events | Five minutes before they start |
| Bluetooth devices | When one connects, with its battery |
| Muted microphone | A red badge while the mic is muted |
| Timers | Named timers and the stopwatch from the Focus tab |
| Downloads | Progress as a file downloads, and a notice when it's done |
| Focus | Your Focus's symbol while one is on, and a notice when it changes |
| Notifications | Messages, Mail, Slack and more as they arrive |

<Note>**Focus** and **Notifications** need [Full Disk Access](/permissions/#full-disk-access), and show nothing without it.</Note>

A few other things use the same space: a Shortcut finishing, a screenshot landing in the Tray, rain about to start, a new version of Dynotch, and whatever your [scripts](/dynotch-command/) say.

## Two at once

A second activity keeps a small glyph at the end of the right ear while another takes the notch: the mute badge, a timer's or a download's ring, the Focus that's on, or the album art.

The main activity follows this order, and the first that applies takes the notch:

1. Notices
2. The song title
3. The timer that ends soonest
4. A download
5. Music

Turn **Two at once** off in <Path to="Settings → Live Activities → Options" /> to show only the main one. A status like the mute badge or your Focus's symbol then shows only when nothing else does.
